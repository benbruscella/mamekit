| CPU | Type | Clock | Mapped ranges |

- **Sound:** sn76489 × 1 @ 3.580 MHz
- **Screen:** 280×216 @ 59.92 Hz

### Cartridges

The machine itself needs no ROMs — all software comes on cartridges. 229 cartridges are catalogued from the MAME `coleco` software list; 9 PCB types are currently supported (`standard`, `megacart`, `xin1`, `activision`, `activision_256b`, `activision_32k`, `sgc_1mbit`, `sgc_2mbit`, `sgc_4mbit`). Drop your own legally-dumped cart files onto the console page to play.
