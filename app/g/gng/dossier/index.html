The story

Arcade Video game published 41 years ago: Ghosts'n Goblins (c) 1985 Capcom. Export release. Game developed in Japan. For more information about the game itself, please see the original Japanese version entry; "Makaimura".

TRIVIA

Ghosts'n Goblins was released in September 1985 outside Japan. These non-Japanese versions use a shield instead of a cross.

UPDATES

A rare prototype version of the game exists with no title logo. It seems to be harder than the final version.
